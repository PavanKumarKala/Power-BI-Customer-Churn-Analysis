# 📊 Customer Churn Analysis — Power BI

An interactive **Power BI dashboard** developed to analyze customer churn patterns and understand the factors associated with customer retention and churn.

## 📌 Project Overview

This project transforms customer data into meaningful business insights using **Power BI, Power Query, and DAX**.

The dashboard focuses on customer demographics, service subscriptions, contracts, billing, tenure, churn drivers, and revenue impact.

## 🔍 Key Analysis

* Customer demographics and tenure analysis
* Churn rate analysis
* Service subscription analysis
* Contract type analysis
* Payment method analysis
* Monthly charges vs. tenure
* Customer churn by tenure
* Retained vs. churned revenue
* Key Influencers analysis for churn drivers
* Interactive slicers and KPI cards

## 🛠️ Tools & Technologies

* **Microsoft Power BI**
* **Power Query**
* **DAX**
* Data Cleaning & Transformation
* Data Modeling
* Data Visualization
* Business Analytics

## 📊 Dashboard Pages

1. **Customer Demographics Analysis**
2. **Service Subscription Analysis**
3. **Contract & Billing Insights**
4. **Churn Prediction & Key Drivers**

## 🎯 Project Objective

The objective of this project is to use data visualization and analytical techniques to understand customer churn behavior and identify patterns that can support data-driven business decisions.
